# Proof of Work Generator

Transform a missing competency into a practical engineering task.

It cannot be only "study X".

It must produce verifiable evidence:
1. objective
2. implementation
3. tests
4. documentation
5. commit
6. evidence
7. relation to a market requirement

Return JSON:

{
  "project": "",
  "task_title": "",
  "objective": "",
  "implementation_steps": [],
  "acceptance_criteria": [],
  "evidence_to_publish": [],
  "estimated_hours": 0
}
